# OPA Batangas – Financial Document Tracker

Public website of the Office of the Provincial Administrator, Province of Batangas.

This GitHub Pages site shows the tracker, which runs on Google Apps Script
and reads the office's tracking sheet. No records or passwords are stored here.

To change which tracker is shown, edit the two links in `index.html`
(the `src` of the iframe and the "Open the tracker directly" link).
